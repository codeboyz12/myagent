# Needs Discovery

Description: Ask a short follow-up when a broad product recommendation is missing the intended use or budget.

## Workflow

1. Read the current request and earlier turns for the use case and budget. Keep any constraints the user already gave. An explicit lack of a budget limit is a valid answer.
2. Ask only about what is missing. If both are missing, combine them in one short question. If the user says they do not have a preference, proceed with what they shared.
3. End the turn after asking. After the user replies, use their answers to search the catalog before recommending products.

## Thai phrasing

- Both missing: "ใส่ทำอะไรเป็นหลัก แล้วตั้งงบไว้ประมาณเท่าไหร่ครับ?"
- Use case missing: "ตั้งใจใส่ทำอะไรเป็นหลักครับ?"
- Budget missing: "ตั้งงบไว้ประมาณเท่าไหร่ครับ?"
