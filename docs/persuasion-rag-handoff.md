# สรุปงาน MyAgent — Skills, RAG และชุดทดสอบ

## สิ่งที่เพิ่ม

- เพิ่ม `needs-discovery` ให้ถามเฉพาะการใช้งานหรืองบที่ยังขาด แล้วใช้คำตอบจากแชตเดิมค้นสินค้าต่อ
- เพิ่ม `objection-handling` ให้ตอบข้อกังวลเรื่องราคาและแนะนำสินค้าจากการใช้งานกับงบ งบคร่าว ๆ สามารถเสนอรุ่นที่เกินงบเล็กน้อยพร้อมส่วนต่างและประโยชน์ที่ได้ ส่วนงบที่เป็นเพดานให้ยึดตามนั้น
- ปรับให้เลือก `comparative-persuasion` เมื่อผู้ใช้ขอเทียบหลายรุ่น และ `relevance-persuasion` เมื่อถามว่ารุ่นเดียวตรงกับความต้องการไหม
- เพิ่มผลค้นใน Agent progress ให้เห็น query, ID, คะแนน และข้อความเอกสาร ส่วนคำตอบใช้สำนวนภาษาไทยแบบร้านค้าและแสดงเลขเอกสารเมื่อผู้ใช้ขอ
- เพิ่มข้อมูลเดโมจาก 3 เป็น 6 รุ่น ได้แก่ Runner A, Office B, Trail C, Road D, Ridge E และ Walk F
- เพิ่ม `.dockerignore` เพื่อกัน `.env` ออกจาก Docker build context

ข้อกำหนดการตอบตาม RAG อยู่ใน prompt และ skills ผลทดสอบด้านล่างใช้ตรวจพฤติกรรมรายกรณี

## รันบนเครื่องเพื่อน

1. คัดลอก `.env.example` เป็น `.env` สร้าง `MYAGENT_SETTINGS_ENCRYPTION_KEY` ของเครื่องตัวเองตามคำสั่งในไฟล์ตัวอย่าง
2. จากโฟลเดอร์ repo รัน `docker compose up -d --build` แล้วรอให้บริการขึ้นครบ
3. รัน `docker compose exec -T vector-service python -m app.seed` ควรได้ 6 รายการเมื่อใช้ฐานใหม่
4. เปิด [MyAgent](http://localhost:3000) สมัครบัญชี local และเชื่อม provider ของตัวเองใน Settings → Connections
5. หยุดบริการด้วย `docker compose stop` แล้วเปิดอีกครั้งด้วย `docker compose up -d`

## ชุดเทสต์ในหน้าแชต

เปิดแชตใหม่ต่อเคส ยกเว้นเคสถามกลับที่ต้องตอบในแชตเดิม กาง Agent progress เพื่อดูชื่อ skill และหลักฐานจากการค้น

| เคส | ข้อความทดสอบ | เกณฑ์ผ่าน |
| --- | --- | --- |
| ถามโจทย์ | มีรองเท้าแนะนำไหมครับ | โหลด `needs-discovery` ถามการใช้งานกับงบในข้อความเดียว |
| ใช้คำตอบจากแชตเดิม | ใส่เดินไปเรียนทุกวัน งบไม่เกิน 1,200 บาท | ค้นเอกสารและแนะนำ Walk F 990 บาท จบด้วยเหตุผลที่เหมาะกับการเดินทุกวัน เก็บยอดเงินเหลือไว้ตอบเมื่อถาม |
| งบโดยประมาณ | ผมจะวิ่งเทรลบนทางดิน ตั้งงบไว้ประมาณ 2,000 บาท มีคู่ไหนบ้างครับ | โหลด `objection-handling` เสนอ Ridge E 2,190 บาทเมื่อเพิ่มงบได้ 190 บาท และอธิบายประโยชน์สำหรับวิ่งเทรลบนทางดิน |
| งบเป็นเพดาน | ผมจะวิ่งเทรลบนทางดิน งบห้ามเกิน 2,000 บาท มีคู่ไหนบ้างครับ | แจ้งว่าทางร้านยังไม่มีคู่ที่ตรงโจทย์ในงบ โดยไม่ชวนให้เพิ่มงบ |

| รูปแบบภาษาไทย | ใส่เดินไปเรียนทุกวัน งบไม่เกิน 1,200 บาท มีคู่ไหนแนะนำไหมครับ | ชื่อและราคาเป็นตัวหนา คำลงท้ายอยู่นอกตัวหนา เช่น **Walk F ราคา 990 บาท** ครับ |

เคสเหล่านี้เป็นเทสต์แบบรันในหน้าแชต เคสงบห้ามเกินแบบไม่ระบุรุ่นเป็นเคสเพิ่มเติมสำหรับทำซ้ำคู่กับงบโดยประมาณ
